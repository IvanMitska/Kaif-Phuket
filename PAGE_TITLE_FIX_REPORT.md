# 🔧 Исправление заголовков страниц при смене языка

## 📋 Проблема

При наведении на вкладку браузера заголовок страницы отображался на русском языке, даже когда был выбран английский или тайский язык.

## ✅ Решение

### 1. Обновлен компонент PageHead

- **Файл**: `src/components/layout/PageHead.jsx`
- **Изменения**:
  - Добавлена поддержка переводов через `useTranslation`
  - Добавлен `useEffect` для обновления `document.title` при смене языка
  - Добавлены параметры для описания, ключевых слов и Open Graph тегов

### 2. Добавлены ключи переводов

- **Файлы**:
  - `src/locales/ru/translation.json`
  - `src/locales/en/translation.json`
  - `src/locales/th/translation.json`
- **Добавлена секция**: `page_titles` с заголовками для всех страниц

### 3. Обновлены все основные страницы

- **HomePage.jsx** - добавлен PageHead с ключом `page_titles.home`
- **RestaurantPage.jsx** - заменен захардкоженный заголовок на PageHead с `page_titles.restaurant`
- **SpaPage.jsx** - добавлен PageHead с ключом `page_titles.spa`
- **SportsPage.jsx** - добавлен PageHead с ключом `page_titles.sports`
- **BanyaPage.jsx** - добавлен PageHead с ключом `page_titles.banya`
- **ContactsPage.jsx** - добавлен PageHead с ключом `page_titles.contacts`

### 4. Обновлен App.jsx

- **Файл**: `src/App.jsx`
- **Изменения**: Добавлен глобальный `useEffect` для обновления заголовка при смене языка

### 5. Обновлен index.html

- **Файл**: `index.html`
- **Изменения**: Заголовок изменен с "KAIF | Jungle Club & Spa" на нейтральный "KAIF"

## 🔄 Как это работает

1. Компонент `PageHead` получает ключ перевода и переводит заголовок
2. `useEffect` в `PageHead` обновляет `document.title` при смене языка
3. Глобальный `useEffect` в `App.jsx` обеспечивает обновление на всех страницах
4. React Helmet управляет мета-тегами для SEO
