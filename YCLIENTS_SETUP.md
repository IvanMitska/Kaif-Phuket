## Что нужно для завершения настройки

### 1. Получить данные из Yclients

Вам нужно получить один из вариантов:

**Вариант А: ID компании**

- Зайдите в админ-панель Yclients
- Найдите ID компании (обычно в настройках или URL)
- Пример: если ваш URL `https://n123456.yclients.com/`, то ID = `123456`

**Вариант Б: Прямая ссылка на виджет**

- В Yclients перейдите в раздел "Интеграции" → "Виджет записи"
- Скопируйте готовую ссылку на виджет записи

### 2. Настроить компоненты

После получения данных, обновите следующие файлы:

#### В `src/components/spa/SpaHeroSection.jsx`:

```jsx
<YclientsModal
  isOpen={isYclientsModalOpen}
  onClose={() => setIsYclientsModalOpen(false)}
  companyId="123456" // Замените на ваш ID
  // ИЛИ
  // customUrl="https://your-company.yclients.com/widget"
/>
```

#### В `src/components/spa/SpaBookingSection.jsx`:

```jsx
<YclientsModal
  isOpen={isYclientsModalOpen}
  onClose={() => setIsYclientsModalOpen(false)}

  // ИЛИ
  // customUrl="https://your-company.yclients.com/widget"

```

## Дополнительные возможности

### Настройка виджета в Yclients

1. **Внешний вид:** Настройте цвета виджета под дизайн сайта
2. **Услуги:** Выберите, какие услуги показывать в виджете
3. **Мастера:** Настройте список доступных мастеров
4. **Время работы:** Установите рабочие часы для записи

### Аналитика

- Yclients предоставляет подробную аналитику записей
- Можно отслеживать конверсию с сайта
- Интеграция с Google Analytics через события

### Уведомления

- Настройте SMS/Email уведомления клиентам
- Автоматические напоминания о записи
- Уведомления мастерам о новых записях

## Тестирование

После настройки протестируйте:

1. **Открытие модального окна** - кнопки должны открывать модальное окно
2. **Загрузка виджета** - iframe должен загружать форму записи
3. **Мобильная версия** - проверьте на телефоне
4. **Процесс записи** - попробуйте записаться на тестовую услугу

## Поддержка

Если возникнут вопросы:

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что URL виджета корректный
3. Проверьте настройки CORS в Yclients
4. Обратитесь в поддержку Yclients для настройки виджета
