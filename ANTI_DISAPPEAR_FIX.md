# Исправление проблемы исчезновения элементов при скролле

## Проблема

При скролле вниз элементы (особенно хедер) исчезают на половину или полностью, что создает плохой пользовательский опыт.

## Причины проблемы

1. **CSS Конфликты**: Анимации и transform правила могут случайно скрывать элементы
2. **Z-index проблемы**: Неправильная иерархия слоев
3. **Viewport анимации**: Aggressive `whileInView` анимации
4. **Mobile оптимизации**: Слишком агрессивные CSS правила для мобильных

## Решение

### 1. Защитные CSS файлы

#### `src/styles/anti-disappear.css`

```css
/* Критическая защита хедера */
header.kaif-header {
  position: fixed !important;
  opacity: 1 !important;
  visibility: visible !important;
  z-index: 99999 !important;
  transform: none !important;
}
```

#### `src/styles/mobile-optimizations.css`

- Ограничил CSS оптимизации только контентом
- Исключил хедер из мобильных transform правил
- Добавил защитные правила для критических элементов

### 2. Автоматическое исправление

#### `src/components/common/hooks/useScrollFix.js`

Хук, который:

- Мониторит состояние хедера каждые 100ms
- Автоматически восстанавливает исчезнувшие элементы
- Логирует проблемы в консоль для отладки

### 3. Диагностический инструмент

#### `src/components/ui/ScrollDiagnostic.jsx`

- Показывает в реальном времени состояние элементов
- Отображает opacity, visibility, transform
- Работает только в development режиме

### 4. Обновленные компоненты

#### Безопасные анимации

```jsx
// ВМЕСТО:
<motion.div whileInView={{ opacity: 1 }} />

// ИСПОЛЬЗУЕМ:
<SafeAnimatedCard delay={0.1}>
  {content}
</SafeAnimatedCard>
```

## Тестирование

1. Откройте страницу контактов
2. Скроллите вниз и вверх
3. Проверьте диагностическую панель (правый верхний угол)
4. Хедер должен оставаться видимым

## Отладка

- Откройте DevTools Console
- Ищите сообщения "🔧 Исправляю исчезновение хедера..."
- Проверьте диагностическую панель на странице

## CSS Селекторы для защиты

```css
/* Принудительная видимость */
.force-visible {
  opacity: 1 !important;
  visibility: visible !important;
  display: block !important;
  z-index: 999999 !important;
}

/* Отключение transform */
.no-transform {
  transform: none !important;
  will-change: auto !important;
}
```

## Интеграция

Система автоматически активируется при импорте CSS файлов в `App.jsx`:

```javascript
import "./styles/anti-disappear.css";
```

И при использовании хука в компоненте:

```javascript
const AppContent = () => {
  useScrollFix(); // Автоматическая защита
  // ...
};
```
